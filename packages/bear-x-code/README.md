# @forgedevstack/bear-x-code

Bear X code tools. CodeEditor, Terminal, DiffViewer, JsonViewer, and DiffSquares. Requires @forgedevstack/bear styles.

```bash
npm install @forgedevstack/bear @forgedevstack/bear-x-code
```

```tsx
import '@forgedevstack/bear/styles.css';
```

Source for 1.3.5 still lives in the Bear repo. This package is the install name. Core keeps the same components exported from `@forgedevstack/bear`.
