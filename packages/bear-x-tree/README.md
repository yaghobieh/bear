# @forgedevstack/bear-x-tree

Bear X tree widgets. TreeView, TreeSelect, FileTree, and Cascader. Requires @forgedevstack/bear styles.

```bash
npm install @forgedevstack/bear @forgedevstack/bear-x-tree
```

```tsx
import '@forgedevstack/bear/styles.css';
```

Source for 1.3.5 still lives in the Bear repo. This package is the install name. Core keeps the same components exported from `@forgedevstack/bear`.
