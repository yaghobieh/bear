# @forgedevstack/bear-x-ai

Bear X AI chat kit. Composer, streaming, tools, citations, and approvals. Requires @forgedevstack/bear styles.

```bash
npm install @forgedevstack/bear @forgedevstack/bear-x-ai
```

```tsx
import '@forgedevstack/bear/styles.css';
```

Source for 1.3.5 still lives in the Bear repo. This package is the install name. Core keeps the same components exported from `@forgedevstack/bear`.
