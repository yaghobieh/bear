Bear 1.3.6: Flutter, icons, and a $9 grid

Core stays free. Flutter and the icon set are free. Bear Grid is $9 a year because pinned columns, row groups, and Excel export are the parts teams budget for. Blocks are the screens you build on top of that.

What stays free

Button, Input, Modal, the theme, and DataTable stay on the MIT core. DataTable still sorts and sticks the header. Ask Bear on the docs stays free. You do not pay to ship a form or a dialog.

Flutter

bear_flutter is the mobile kit. It uses the same color, radius, space, and type as Bear. The first widgets are a button, text field, card, app bar, list, dialog, and bottom sheet. Web stays React. Mobile stays Flutter. This kit is free.

flutter pub add bear_flutter

Icons

Icons are a separate install, @forgedevstack/bear-icons. Core still renders if you leave them out. The home page and /icons browse the set.

npm install @forgedevstack/bear-icons

What Blocks are

A block is a finished screen made from Bear components. DashboardBlock is the first one: a title and stat cards. It is free, so you can see the pattern and drop a dashboard in without a license. A block is not a locked button. It is the layout you would otherwise copy from a screenshot. You do not pay for the block. You pay when the table under the cards has to pin a column, group rows, or export Excel. That table is Bear Grid.

Why the $9 is for the grid

The screen stays useful with the free DataTable. You pay when the table has to behave like a spreadsheet: pin a column while you scroll, group rows by team, and download Excel. That is Bear Grid. One key covers one app for a year. The intro price is $9. Pay on Premium, and the key is emailed to you. That key clears the watermark. Without a key the grid still runs, with a Bear Pro mark, so you can try it.

npm install @forgedevstack/bear @forgedevstack/bear-grid

En español

Core sigue gratis. Flutter y los iconos son gratis. Bear Grid cuesta $9 al año porque fijar columnas, agrupar filas y exportar Excel es lo que los equipos presupuestan. Los bloques son las pantallas que construyes encima.

Un bloque es una pantalla terminada hecha con componentes de Bear. DashboardBlock es el primero: un título y tarjetas de cifras. Es gratis. No pagas por el bloque. Pagas cuando la tabla tiene que fijar una columna, agrupar filas o descargar Excel. Eso es Bear Grid. Una clave cubre una app durante un año. Pagas y la clave llega por email. Esa clave quita la marca de agua.
